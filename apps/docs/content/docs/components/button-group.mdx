## Usage

Use a button group for two to four actions on the same thing. Give every member the same variant, so the group reads as one control: grouped secondaries share a single 1px seam. The group is one Tab stop, and the arrow keys move between its buttons. Its `label` names it for screen readers.

To switch between views or modes, use a [segmented control](/docs/components/segmented-control) instead. For more than four actions, use a [toolbar](/docs/components/toolbar) or a [dropdown menu](/docs/components/dropdown-menu).

```tsx
import { Button } from "@astryxdesign/core/Button";
import { ButtonGroup } from "@astryxdesign/core/ButtonGroup";

<ButtonGroup label="Zoom">
  <Button label="Zoom out" />
  <Button label="Zoom in" />
</ButtonGroup>;
```
