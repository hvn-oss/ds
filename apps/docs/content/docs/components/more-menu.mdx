## Usage

Use a more menu for the secondary actions on a row, a card or a toolbar. Keep the main action visible beside it, not inside it. Set `alignment="end"`, so the menu lines up with the button's trailing edge.

`label` names the button for screen readers and is its tooltip. Name what the actions belong to, such as "Document options", when a page has more than one more menu.

```tsx
import { MoreMenu } from "@astryxdesign/core/MoreMenu";

<MoreMenu
  alignment="end"
  items={[{ label: "Rename" }, { label: "Delete", variant: "destructive" }]}
/>;
```
