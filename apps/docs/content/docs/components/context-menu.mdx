## Usage

Wrap the element the actions belong to, and pass the menu's rows as `items`. Not everyone knows to right-click, so every action in a context menu must also be reachable some other way, such as a [more menu](/docs/components/more-menu) on the same row. The menu uses the same panel and rows as a [dropdown menu](/docs/components/dropdown-menu).

```tsx
import { ContextMenu } from "@astryxdesign/core/ContextMenu";

<ContextMenu label="File actions" items={[{ label: "Rename" }, { label: "Delete" }]}>
  <FileRow />
</ContextMenu>;
```
