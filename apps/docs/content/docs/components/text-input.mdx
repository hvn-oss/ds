## Usage

A text input is controlled: pass its `value` and update it in `onChange`. Every input needs a `label`, even when it's hidden with `isLabelHidden`, so screen readers can name it.

```tsx
import { TextInput } from "@astryxdesign/core/TextInput";

const [name, setName] = useState("");

<TextInput label="Name" value={name} onChange={setName} />;
```
