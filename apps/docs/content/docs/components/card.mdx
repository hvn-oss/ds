## Usage

Use a card to set one piece of content apart, such as a summary, a record or a prompt. For lists of many similar items, use rows instead, such as a table or a list.

```tsx
import { Card } from "@astryxdesign/core/Card";

<Card>
  <Text>Sign-ups grew 12% this week.</Text>
</Card>;
```
