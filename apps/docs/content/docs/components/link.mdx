## Usage

Use a link to go somewhere. For an action on the current page, use a [button](/docs/components/button) instead. Write link text that names the destination, never "click here".

A link in running text always sets `hasUnderline`. Blue alone isn't enough to set a link apart from grey supporting text, so the underline does it. A standalone link sets `isStandalone` instead, and underlines on hover.

```tsx
import { Link } from "@astryxdesign/core/Link";

<Text>
  Change this in your{" "}
  <Link href="/settings/billing" hasUnderline>
    billing settings
  </Link>
  .
</Text>;
```

To navigate with your app's router, wrap the app in a `LinkProvider`, or pass the router's link component as `as`.
