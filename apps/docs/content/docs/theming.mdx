title: Theming
description: What the hvn theme changes in Astryx, and how to build on it.
---

The `hvn` theme gives Astryx components the hvn look: quiet and mostly monochrome, with pure-grey neutrals, flat white surfaces with hairlines, and blue as the one accent. Every colour, font and radius reaches components as a CSS variable, so apps style with tokens rather than raw values.

## What the theme sets

| Foundation                                                   | In short                                                               |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| [Colour](/docs/foundations/colour)                           | A generated palette, with Tailwind's blue-600 as the accent            |
| [Typography](/docs/foundations/typography)                   | Inter for text and headings, JetBrains Mono for code, on a 14px base   |
| [Shape and elevation](/docs/foundations/shape-and-elevation) | Radii of 4, 8, 16 and 24px, 1px borders, and ring-and-shadow elevation |
| [Icons](/docs/foundations/icons)                             | Free Hugeicons, stroke rounded, behind every semantic icon             |

Each token has a light and a dark value, and the theme follows the system's colour scheme by default. The theme self-hosts its fonts through `@hvn-oss/ds/themes/hvn.fonts.css`, which `astryx theme add` imports for you.

## Customise the theme

Don't copy the theme's source. Define your own theme that `extends` it, and override only what you need:

```tsx
import { defineTheme } from "@astryxdesign/core/theme";
import { hvnTheme } from "@hvn-oss/ds/themes/hvn";

export const brandTheme = defineTheme({
  name: "brand",
  extends: hvnTheme,
  tokens: {
    "--radius-element": "0.25rem",
  },
});
```

Everything you leave out carries over from `hvn`. Build the file with `npx astryx theme build <path>`, then add the result as a local theme so the generated `astryx-themes.ts` imports it. See [Astryx](https://astryx.atmeta.com) for every token and how theme inheritance works, or run `npx astryx docs author-a-theme`.
