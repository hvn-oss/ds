hvn ds is a UI library and design system built on top of a base library, in the same spirit as [shadcn/ui](https://ui.shadcn.com). It ships themes and components, and documents them here.

## Base library

The design system builds on [Astryx](https://astryx.atmeta.com). Astryx components and tokens are the raw material: hvn ds gives them its own look through the `hvn` theme.

> Visual polish waits until the `hvn` theme is finalised.

## What's in the package

| Export                             | What it is                 |
| ---------------------------------- | -------------------------- |
| `@hvn-oss/ds/themes/hvn`           | The `hvn` theme for Astryx |
| `@hvn-oss/ds/themes/hvn.css`       | The theme's CSS variables  |
| `@hvn-oss/ds/themes/hvn.fonts.css` | The theme's fonts          |

## Using a theme

Wrap your app in Astryx `Theme` and pass it the `hvn` theme:

```tsx
import { Theme } from "@astryxdesign/core/theme";
import { hvnTheme } from "@hvn-oss/ds/themes/hvn";

export function App({ children }: { children: React.ReactNode }) {
  return <Theme theme={hvnTheme}>{children}</Theme>;
}
```
