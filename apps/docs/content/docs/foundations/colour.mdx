title: Colour
description: Quiet, mostly monochrome colour, with blue as the one accent.
---

hvn is quiet and border-led. Neutrals are pure grey, surfaces are flat white with hairlines between them, and blue is the only accent. Blue marks primary actions, focus, links and selection. Other hues appear only when they mean something: a status, a category or a chart series.

Every colour comes from Astryx's generated palette, at vibrancy 50. Each family is seeded from its Tailwind 500, and the accent is Tailwind's blue-600 (`#2563EB`), pinned at stop 45 in both modes. Components reach colours only through the tokens below, so style with tokens too, never with palette stops or hex values.

Each token has a light and a dark value. The tables show both, whatever mode you're reading in.

## Status

Pick the token by the surface it sits on:

- On the strong fill, such as `--color-info`, use `--color-on-info`.
- On the pale fill, such as `--color-info-muted`, use `--color-on-info-muted`.
- On the page, use `--color-text-info`. Status icons and borders follow the status text colour.

## Border

Hairlines use `--color-border`. Input and secondary-control outlines use `--color-border-emphasized`, which is quiet by choice: it falls below the 3:1 non-text minimum. A component that relies on that outline needs another cue as well, such as a label, a fill or the focus ring.

## Categorical

`--color-{background,border,icon,text}-<hue>` colour feature icons, tags and category markers. Each hue pairs a pale surface with a deep foreground: stops 90, 80, 40 and 30 in light mode, and 25, 35, 75 and 85 in dark mode. Gray uses the neutral family.

## Data

Chart colours come from the same palette. Categorical series share one stop per mode, 55 in light and 60 in dark, so they differ only by hue and all pass 3:1 on the page. Brown borrows yellow and indigo borrows blue, at a different lightness. Use `--color-data-neutral` for an "other" or baseline series.

## Syntax

Code blocks use the theme's syntax colours. Each role keeps one hue in both modes, at the same stops as status text. Identifiers, operators and punctuation use the primary text colour, and comments use the secondary one.
