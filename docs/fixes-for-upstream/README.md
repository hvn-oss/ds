# Fixes for upstream

Drafted requests for fixes in the libraries hvn builds on (Astryx, Hugeicons, Paper and others). Each one is for a problem hvn works around locally that an upstream change would solve better. There's one file per request, written as an issue ready to file.

Each file starts with:

- **Upstream**: where it would be filed.
- **Status**: `draft, not filed`, then the issue link once filed.
- **Checked against**: the versions confirmed to still have the problem.
- **hvn workaround**: the local code it replaces and the decision that chose it.
- **When it lands**: the steps to remove the workaround. Delete the file as the last step.

Only the user files a request. Before filing, check the latest upstream version and update **Checked against**.
