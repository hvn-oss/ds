# PROTOTYPE · Typography foundation (throwaway, never merged)

Prints the size/line-height for every Astryx type style at base 14 and ratios 1.125–1.25,
using Astryx's own `expandTypeScale`. These numbers fed the comparison boards on the
"PROTOTYPE · Typography foundation" page of the Design file.

Run from `packages/ds/prototype-typography`: `vp node scale.mjs`
